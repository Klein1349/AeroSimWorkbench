# 前处理网格样例

本目录提供 14 个可直接选择导入的网格文件，覆盖 `.cgns`、`.vtk`、`.vtu`、`.vtp` 和 `.vti`。正方体与立方体指同一种几何，另提供长方体和三棱锥以便比较形状。坐标单位为米，文件包含几何与拓扑。

## 文件与几何

| 文件名前缀 | 几何 | 可用扩展名 | 点数 | 体积（m³） | 外表面 |
| --- | --- | --- | --- | --- | --- |
| `cube` | 边长 1 的正方体 | `.cgns`、`.vtk`、`.vtu`、`.vtp`、`.vti` | 8 | 1 | 6 个四边形 |
| `cuboid` | 2 × 1 × 0.5 的长方体 | `.cgns`、`.vtk`、`.vtu`、`.vtp`、`.vti` | 8 | 1 | 6 个四边形 |
| `triangular_pyramid` | 三条直角边长均为 1 的三棱锥 | `.cgns`、`.vtk`、`.vtu`、`.vtp` | 4 | 1/6 | 4 个三角形 |

同一几何的各格式具有相同的外表面。`.cgns`、`.vtk` 和 `.vtu` 各含 1 个体单元，正方体与长方体使用六面体，三棱锥使用四面体。`.vti` 使用 2 × 2 × 2 个网格点、1 个体素单元。`.vtp` 直接保存表面的三角形或四边形。

`.vti` 表示规则笛卡尔体网格，因此三棱锥提供其余四种格式。

| 几何 | X 范围 | Y 范围 | Z 范围 |
| --- | --- | --- | --- |
| 正方体 | [-3, -2] | [0, 1] | [0, 1] |
| 长方体 | [0, 2] | [0, 1] | [0, 0.5] |
| 三棱锥 | [3, 4] | [0, 1] | [0, 1] |

三棱锥的四个顶点为 `(3, 0, 0)`、`(4, 0, 0)`、`(3, 1, 0)`、`(3, 0, 1)`。三种几何沿 X 轴分开放置，适合一次导入后同时观察。导入同一几何的多个格式时，其表面会位于相同位置。

## 在工作台中使用

1. 打开前处理工作区的网格管理页面，点击“导入”。
2. 进入源码目录下的 `examples/preprocess/meshes`。例如目标机源码位于 `F:\AeroSimWorkbench` 时，完整目录为 `F:\AeroSimWorkbench\examples\preprocess\meshes`。
3. 一次选择 `cube.cgns`、`cuboid.vtu` 和 `triangular_pyramid.vtp`，等待三行加载完成，再点击“适合大小”查看三种几何。
4. 分别选中网格，检查颜色、可见性、比例与旋转。也可按文件名前缀逐个比较各格式的外表面。

CGNS 导入需在构建时找到 CGNS 头文件与库，并启用 `AEROSIM_BUILD_MESH_VIEWER`。运行进程还需能定位 CGNS、VTK 和 Qt 的动态库。依赖配置与完整验收步骤见[前处理网格说明](../../../docs/PreprocessMeshImport.md)。

## 文件格式与验证范围

- VTK 文件采用 ASCII 编码，legacy `.vtk` 使用 4.2 格式，XML 文件使用 0.1 格式。几何由 VTK 9.3.1 writer 生成，单元均为项目读取器支持的线性单元。
- `.cgns` 为通过官方 CGNS 4.4.0 C API 生成的 ADF 文件，各含一个三维 Base、一个非结构 Zone 和一个体单元段，坐标标注为米。官方 `cgnscheck` 检查三个文件均无警告、无错误，官方 API 读回核对了坐标、连接和单元类型。
- 14 个文件均通过本地 VTK 9.3.1 reader 读回，包括使用 `vtkCGNSReader` 读取三份 CGNS 文件。点数、单元类型与数量、坐标范围、外表面数、闭合性、表面积和体积均与几何定义一致。目标 Windows 的 Qt 5.12.12 / VTK 8.2.0 工作台导入仍需按上面的步骤实测。

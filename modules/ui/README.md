# 主界面

后处理最新操作顺序、按网格/字段类型启用菜单的规则与背景设置见
[后处理工作台操作流程](../../docs/PostProcessUserWorkflow.md)。工作台默认显示明确标记的界面示例；
可通过“工具 → 界面示例”切换结构和非结构网格示例。当前完成的是 UI 草稿交互，真实读取、
空间算法、VTK 渲染和导出尚未接入。菜单联动和背景测试用例已更新，本次未运行构建或测试。

`aerosim_ui` 是独立的 C++14 / Qt 5.12.12 / SARibbon 2.9.3 主窗口库，GUI 入口已从 `MockWindow` 切换到 `aerosim::MainWindow`。遵循《框架设计与技术调研.统一修改版》的五区布局。

应用默认先显示独立的 `StartupLandingPage`，采用蓝色竖向导航与浅色内容区，提供开始、新建、打开、保存工作区、保存模板、另存为和关闭工作区七个前端入口。最近工作区、内置模板和文件操作均明确标记为 Mock / 占位，不执行文件读写。双击最近项、点击“新建工作区”或打开页的 Mock 按钮后进入原有主工作台；主工作台在“前处理”标签左侧提供固定的“返回欢迎页”按钮，并保留“前处理 → 工作区 → 返回欢迎页”入口，两者复用同一页面切换信号。`aerosim_gui --workbench` 可用于开发期直接启动主工作台，`--postprocess` 行为不变。

- 顶部采用 Word 风格三行 Ribbon，按顺序包含前处理、参数设置、计算、智能数据处理、后处理分析五个业务页签，以及末尾的全局“帮助”页签。大按钮和三行小按钮混排，每个命令使用内嵌 SVG 图标；帮助页签不增加工作区树节点，也不切换中央业务页面。
- 左侧始终显示一棵统一工作区树，根节点下同时包含五个模块。点击 Ribbon 标签会展开、选中并滚动定位对应模块，同时恢复该模块上次访问的中央页面；不重建工作区树。WorkflowView 仍供运行门控使用，但不占用导航区。
- 前处理节点包含网格管理和弹道设置；参数设置节点包含七个不可继续展开的类别节点；计算节点整合工况、批处理计划、单次/批量计算和任务监控。智能数据处理与后处理分析当前只保留不可展开入口。点击具体节点时会反向选择所属 Ribbon 标签，并通过同步保护避免循环定位。
- 主显示区复用一个持久 VTK 视口插槽，并提供网格/弹道、参数入口、计算概览、工况、批处理计划、综合监控和两个预留模块页面。五大模块分别保存上次页面；页面切换不重建或销毁 VTK 插槽。
- “前处理 → 网格管理”使用独立的 `MeshManagementPage`：页内左侧可添加、移除和分别编辑最多 10 个 Mock 网格对象，右侧仍承载原 `WidgetSlot::Viewport` 且不持有 VTK 对象，底部是可折叠的页内操作历史和禁用的脚本预留页。网格页模式下隐藏共享属性 Dock，首次进入时折叠全局输出；离开页面后恢复共享属性 Dock，且不覆盖用户后续对输出面板的手动展开状态。显隐、颜色、透明度、比例和单位只保存当前窗口的前端状态，不执行文件 IO、几何变换或渲染。
- 参数类别在主窗口中央打开嵌入式设置页，并隐藏三维视口和右侧属性栏。数值变化仍通过模块内 `parameterDraftChanged` 信号通知，尚未实现专业校验或文件持久化。
- 底部仅保留统一“输出”面板；日志、警告和错误按级别、模块、关键字与当前对象范围筛选。计算监控、收敛趋势和任务列表位于计算模块对应的主显示区。
- 计算监控页在曲线下方提供当前任务专用的等宽文本日志区，通过可拖动分隔条调整高度；单任务与批处理子任务共享该页面，并按任务保存 Mock 日志与滚动位置。日志区可筛选 stdout/stderr、暂停自动滚动、清空当前显示，并用按钮演示逐行追加和同一进度行更新。它不复制底部全局输出，也尚未接入真实求解器流。
- “计算”概览页提供“窗口内输出 / 独立控制台”的前端配置入口；默认窗口内输出，独立控制台仅保存当前窗口内的 Mock 选择状态，不启动进程或执行输出重定向。
- 面板支持停靠、浮动、关闭和界面工具恢复。状态栏明确标出未接入能力。

工程树“参数设置 → 控制方程”提供基础参数草稿：计算类型（定常计算 / 非定常计算）、
求解方程（欧拉方程 / N-S 方程）、层流 / 湍流、六种湍流模型与稀薄气体效应开关。
默认按新参考图设置为定常、N-S、湍流、S-A，并启用稀薄气体效应；已有草稿优先恢复。
切换页面保留当前窗口内的设置，“清除本页草稿”恢复默认值。
面板通过 `parameterDraftChanged("physics", draft)` 发出完整 UI 草稿，键为
`calculationType`（`steady` / `unsteady`）、`equation`（`euler` / `navier-stokes`）、
`flowRegime`（`inviscid` / `laminar` / `turbulent`）、`turbulenceModel`、`rarefiedGas`（布尔值）。
湍流模型按参考提供 S-A（`sa`）、k_w Menter（`kw-menter`）、des（`des`）、ddes（`ddes`）、
wilcox k_w1998（`wilcox-kw1998`）、wilcox k_w2006（`wilcox-kw2006`），采用单行互斥单选。
欧拉方程采用无粘流；N-S 可选层流或湍流，只有选中湍流才显示模型设置。切换方程保留先前的粘性流态。
稀薄气体设置包括 `collisionEquation`（`bgk`）、`collisionSubmodel`（`standard-bgk` / `es-bgk`）、
`knudsenNumber`（正数，默认 1）、`freestreamParticleCount`（正整数，默认 100）、
`gridParticleCount`（正整数，默认 2）、`collisionModel`（`vss` / `hs` / `vhs`，默认 `vss`）。
关闭稀薄气体效应收起相关参数，重新勾选恢复显示并保留值；这些选项仍是窗口内 UI 草稿，未写入求解器输入或执行专业校验。
参数设置嵌入主窗口中央区域，选择左侧工程树中的参数项时隐藏三维视口和右侧属性栏，
由设置页填满中央区域；顶部 Ribbon、左侧工程树和底部输出面板保留。
“返回三维工作区”恢复视口，再次打开保留草稿，不创建独立设置窗口。
控制方程采用基础设置和稀薄气体两张卡片，选项全部使用互斥单选按钮；
字体和字号沿用其他参数页的公共设置，不单独放大。模型与粒子参考参数分列，设置区支持垂直滚动。
所有参数页共用主窗口主题：页面、滚动视口和内容容器使用一致背景，
卡片、表格和输入控件统一边框与间距；浅色与深色切换会同时更新已打开的参数页。
滚动区无外框，返回工作区与清除草稿按钮位于同一行。

“边界条件”页提供 M6 示例边界表（symmetry、wing_up、wing_edge、wing_down、farfield），
显示边界名称、边界类型和所属网格。选中边界后可编辑名称及类型，按参考图提供 16 种：
远场、自由来流、对称面、重叠网格、超声速出口(外推边界)、无粘壁面及其壁面函数版本、
无滑移绝热壁面及其壁面函数版本、无滑移等温壁面及其壁面函数版本、质量流量亚音速出口/入口、
压力亚音速出口/入口、超音速和亚声速混合压力出口。类型名称在下拉选项、表格和草稿恢复中一致，
既有对称面、无粘壁面、远场草稿标识保持兼容。这些选项仅表示 UI 类型，未连接对应求解器参数。
“应用”会校验名称非空且同一网格内不重复，然后更新当前窗口草稿并发出
`parameterDraftChanged("boundary", draft)`；数据仍是示例数据，尚未接入实际网格或求解器。

远场类型在边界编辑区显示攻角、侧滑角、马赫数及来流参数。支持单位雷诺数和静温、静压和静温、
总压和总温、高度四种组合，只显示对应字段；默认静压 955 Pa、静温 60 K、马赫数 3、角度 0。
切换组合保留隐藏值；“应用”按边界 ID 保存完整 `farfield` 子草稿，切换边界放弃未应用修改，
不同边界的参数相互独立。非远场类型隐藏这一设置区，已应用参数保留。窄窗口自动上下排列表格和编辑区。

无滑移等温壁面（含壁面函数版本）显示壁面温度，默认 300.0 K；质量流量亚音速出口显示质量流量，
默认 100.0；质量流量亚音速入口另显示总温，默认 300.0 K。数值默认显示一位小数并保留更多输入精度。
这些字段紧跟边界类型，仅在对应类型显示；`typeParameters` 按边界和类型分别保留已应用草稿，
不同类型的质量流量互不覆盖，切换边界放弃未应用修改。质量流量单位待求解器契约确认，界面沿用参考图标签。

压力亚音速出口显示出口静压（默认 1000.0 Pa）；压力亚音速入口显示压力松弛因子（1.0）、
进口温度（300.0 K）和进口总压（1000.0 Pa）；超音速和亚声速混合压力出口显示压力松弛因子（1.0）
及出口静压（1000.0 Pa）。字段随类型切换，仍使用按边界、按类型独立保存的 `typeParameters` 草稿。

“网格运动”页默认关闭动网格，运动体数目为 0。启用后可设置 0–100 个运动体，逐行编辑
名称、目标网格/对象名称和运动类型，并通过“设置参数”在页内编辑速度分量。当前草稿提供
运动类型提供强迫运动、定轴转动、六自由度运动和旋转抛置；已移除旧的独立平移、旋转选项与内联速度编辑区。
修改自动写入当前窗口 `motion` 草稿；停用或减少数目保留已有记录，重新启用/增加数目可恢复，
清除草稿恢复默认状态。真实网格对象绑定、运动校验及动网格求解尚未接入。

新建运动体默认选择强迫运动，点击“设置参数”弹出强迫运动参数窗口。支持重心位置、无旋转、
匀速旋转和正弦旋转；有旋转时显示中心、方向、开始时间和持续时间（默认 1e99 s）。
匀速旋转提供角速率，正弦旋转提供旋转频率/减缩频率切换以及相位、偏移值和振幅。
平移运动类型按参考图暂提供无平动。确定保存到该运动体的 `forcedMotion` 草稿，取消不修改，
切换选项保留已输入字段。旧草稿的独立平移/旋转类型回退为强迫运动，原草稿字段保留。

“定轴转动”通过设置按钮打开独立窗口，支持方向定义/两点定义、转动惯量（默认 1 kg·m²）、
重心位置和忽略气动力矩。外力默认 1 个、每个默认 2 个渐变点，分别编辑 Fx/Fy/Fz、Px/Py/Pz 和时刻；
参考系支持惯性系、随体系。切换外力或减少再增加点数保留窗口内数据，保存按钮保存当前外力到
窗口草稿，确定提交该运动体的 `fixedAxisMotion`，取消放弃本次窗口修改。未执行实际动力学计算。

“六自由度运动”设置窗口包含质量、重心、六个惯性矩分量、初始线速度/角速度/姿态角、
三个平动及三个转动方向约束、重力方向与大小。质量和主惯性矩默认 1，重力默认 (0,0,-1)、9.8 m/s²。
外力与力矩各默认 1 项、每项默认 1 个渐变点，参考系为惯性系/随体系；切换项目、减少再增加
数量或渐变点均保留草稿。确定提交该运动体的 `sixDofMotion`，取消不修改原草稿；尚未接入动力学求解。
外力或外力矩数目为 0 时，隐藏相应渐变设置区域；恢复数目后重新显示并保留原参数。
定轴转动的外力设置也遵循相同的隐藏规则。

“旋转抛置”复用刚体参数与载荷编辑界面，分为转轴和运动体两组。支持方向/两点定义转轴、
转动惯量、最大旋转角（默认 0°）、忽略气动力矩；运动体部分包含质量、重心、惯性矩、
方向约束和重力，不提供六自由度窗口的初始速度与姿态字段。外力及外力矩默认 0，设置区域隐藏。
确定校验转轴有效并提交独立的 `rotationReleaseMotion` 草稿，取消放弃本次修改，尚未接入动力学求解。

未实现的工程保存、网格导入、后处理和暂停/续算等操作禁用并提供提示；配置入口仅打开草稿。收敛曲线和 CPU/MPI 等指标不生成虚构数据。

## 接入边界

主窗口实现已有 `IWidgetHost`。Viewport、Log、Error、Monitor 各接受一次组件插入，成功后 Qt 父对象管理组件；失败不转移所有权。必须在 GUI 线程插入。原内置显示隐藏但保留，避免排队事件访问已释放控件。已插入组件若被销毁，可以重新插入。

`bindServices` 允许重复绑定和解除绑定，不重复连接。事件使用 `Qt::QueuedConnection`。`view()`、`requestRun()` 是同步契约，只在服务与窗口同线程时调用；服务内部应异步执行耗时任务。

`setRunContext` 接收服务提供的工况及参数快照，不从 UI 草稿构造已校验快照。当前 UI 仅识别 actionId 为 `run` 的运行操作（模块接入约定，不修改公共契约）；服务未提供此操作时保持禁用。不同工况及旧版本视图不覆盖当前已绑定工况。步骤、操作、问题可激活并发出 `navigationRequested(pageId, objectId, fieldKey)`；专业模块负责具体字段定位。

## 构建

GUI 现在必须显式提供 SARibbon 2.9.3 源码，无自动下载。库来源为 https://github.com/czyt1988/SARibbon ，MIT 许可证；沿用已批准的 2.9.3 基线，静态编译且关闭 FramelessHelper。无需 VTK 即可构建窗口。

Windows 主工程：

```bat
set "AEROSIM_QT_ROOT=C:\Qt\5.12.12\msvc2017_64"
set "AEROSIM_SARIBBON_SOURCE_DIR=<本机 SARibbon 2.9.3 源码目录>"
scripts\build-windows.cmd all Debug
build-windows\Debug\aerosim_gui.exe
```

独立模块（路径由本机传入）：

```sh
cmake -S modules/ui -B build-ui -DCMAKE_PREFIX_PATH=<Qt目录> -DSARIBBON_SOURCE_DIR=<SARibbon源码目录>
cmake --build build-ui --config Debug
cd build-ui
ctest -C Debug --output-on-failure
```

无界面构建仍使用 `AEROSIM_BUILD_GUI=OFF`，不依赖 SARibbon / Widgets / VTK。截图命令：`aerosim_gui --screenshot <输出PNG路径>`，保存窗口截图后退出。当前验证范围见 [主界面验证记录](../../docs/ui-validation.md)。

## 合并后的后处理工作台


`aerosim_ui` 提供后处理工作台 `PostProcessWorkbenchWindow`。窗口实现
`aerosim/ui/IntegrationPorts.h` 中的 `IWidgetHost`，由 `app/` 装配工作流和任务
服务；工作流规则、工程持久化、数据读取和 VTK 场景实现均不在本模块。

当前工作台包含：

- 顶部只有一层 SARibbon，保留“数据、显示、特征、分析、工具”分类；“数据”首页在同一 Ribbon 中集成导入/导出、交互、显示、空间特征、视图和查询操作，不再叠加第二条快捷工具栏；
- 左侧“视图 / 数据 / 对象”标签页，可独立关闭并从“工具 → 面板”重新打开，依次管理当前 Frame 的全局图层、结果集/Zone/字段/时间帧，以及派生对象层级；
- 中央活动 Frame 视口插槽；未接入时显示明确标记的预览、Frame/字段/时间状态和方向提示，正式 Viewer 以 `WidgetSlot::Viewport` 注入；
- 默认只有左侧导航和中央画布，不再常驻“属性 / Probe / 任务”检查器；对象样式与参数通过对话框编辑，探针结果及任务消息按需打开；
- 底部时间轴和可展开的消息面板。

Ribbon 当前只发送或记录操作请求，不伪造尚未实现的数据、特征或渲染行为。实际
VTK Viewer、统一场景入口和异步数据读取应分别由后续 `modules/visualization/scene`
与数据服务提供；UI 不直接持有 renderer、actor 或 VTK 数据对象。

`aerosim_postprocess_ui_smoke` 验证核心控件以及视口插槽只能接受一个 Viewer。

后处理窗口源码位于 `include/aerosim/ui/postprocess/` 与 `src/postprocess/`，测试位于
`tests/postprocess/`。开发期的 Mock 入口只用于切换 P0/P1 的会话初始状态；它明确不
承担数据读取、VTK 算法或场景管理，真实工程选择服务接入后将替换该入口。

`aerosim_gui` 默认先显示启动欢迎页，进入后显示统一工作区树主窗口；`--workbench` 可直接进入主窗口，`--postprocess` 可直接进入后处理工作台。另提供独立程序 `aerosim_postprocess`：它在单独进程中启动后处理，可与主界面同时运行，关闭主界面不关闭该独立程序。Windows Debug 使用 `scripts\run-postprocess-windows.cmd` 构建并启动；生成文件及部署依赖位于 `build-windows\postprocess\Debug`（可用 `AEROSIM_BUILD_DIR` 覆盖构建目录）。这两个进程各自装配服务，当前服务是 Mock，不共享会话或选择状态。

主界面进程不会锁住独立后处理程序的 EXE 和部署目录。已有的 `aerosim_postprocess.exe` 若正从该目录运行，重新链接它时仍可能遇到文件占用；脚本不会自动关闭任何进程。全量构建若需要重新链接正在运行的主界面 EXE，仍可能遇到主界面的文件占用。

真实 Viewer 将由后续 `modules/visualization/scene` 实现后经 `app/` 注入工作台；当前工作台始终使用明确标记的视口占位。`--screenshot` 可与 `--postprocess` 组合检查工作台。

## 后处理视觉与布局检查

后处理保留自己的数据/对象导航与画布内容，以参考主界面的浅灰标题栏、白色 Ribbon、蓝灰工作区、
Microsoft YaHei UI 9pt 和线性 SVG 图标统一视觉。图标通过本模块的
`PostProcessIcons.qrc` 打包，并由 Qt Svg 渲染多种尺寸；SVG 不依赖字库中的装饰符号。
SARibbon 静态资源必须显式注册，否则主题、标题栏图标会退回系统默认样式。

工作区样式单独作用于中央控件，避免输入框和按钮规则污染 Ribbon。对象编辑使用独立对话框，视口标题/字段分两行，时间步进使用由图标尺寸决定大小的工具按钮。
附加停靠面板的标题使用布局计算高度，避免 Qt 5.12 原生标题区与 QSS padding 不一致导致裁切。

`aerosim_postprocess_ui_smoke` 除功能检查外，也检查 1120×680、1440×960 下的控件几何、
图标资源、停靠标题及是否意外出现第二层工具栏。设置 `AEROSIM_UI_CAPTURE_DIR` 后可导出
五个 Ribbon 页、样式/参数对话框及按需面板的截图。Windows 视觉复查应使用
`QT_QPA_PLATFORM=windows`；再设 `QT_SCALE_FACTOR=1.5` 检查 150% 缩放。
CTest 的 offscreen 测试负责装配与几何回归，不代替原生字体截图验收。

## 对象编辑与探针交互

- 选中数据/对象只更新当前选择和动作可用性，不自动弹窗，也不占用右侧空间。
- “对象样式…”位于左侧视图页和 Ribbon 显示组；Zone 双击、数据/对象右键菜单也可打开。
  对话框编辑颜色、网格、显隐与不透明度。字段、时间节点不作为可修改样式的场景对象。
- 派生对象双击或“编辑参数…”打开对应的切面、等值面、流线、轨迹参数对话框；字段与曲线
  也有各自设置页。“保存草稿”仅修改窗口内按对象 ID 保存的 UI 草稿，“取消”不写入。
  尚未连接真实渲染、计算或参数校验；不会把编辑动作声明成已执行算法。
- “探针”与选择、框选、平移、缩放、旋转互斥，只启用取点模式，不主动展开空结果栏。
  “面板 → 探针结果”以及工具分类中的同名入口只控制结果面板，保持当前鼠标模式。
  关闭结果栏不会退出取点；切换回“选择”等模式即可退出。
- 模块内 Qt 槽 `displayProbeResult(QString)` 接收已经格式化的展示文本，自动打开结果面板，
  用纯文本呈现且保留最后结果。它是 UI 展示入口，不是新公共数据契约，也不执行拾取。
  应在 GUI 线程调用，跨线程使用 `Qt::QueuedConnection`；真实 Viewer/服务尚未连接。
  当前只支持左侧列表/树的双击；画布对象双击必须等待 Viewer 提供真实对象命中事件，
  不把双击预览空白处伪装为命中某个 Zone。
- “面板 → 任务与消息”按需打开底部任务日志。它接收既有任务事件，不创建伪造的任务进度。

## 窗口皮肤

主窗口固定使用默认浅色模式：Office 蓝色标题栏与页签背景、浅色命令区和工作区。
“帮助 → 外观设置”显示“浅色模式（已固定）”，主题切换入口及选项禁用。
启动时将旧的深色或其他主题记录统一恢复为 `office-blue`，不改变布局和业务草稿。
独立后处理工作台继续沿用自己的浅色主题。

“帮助 → 界面布局”维护唯一一份用户主动保存的布局。`QMainWindow::saveGeometry/saveState` 保存窗口及 Dock 基础状态，额外保存工作区/属性 Dock、全局输出、网格对象与 VTK 区域、网格操作记录、监控曲线与任务日志的相对比例和折叠状态。恢复时根据当前 `QScreen::availableGeometry()` 重算尺寸，并对比例、最小宽高和窗口位置做边界限制；不同分辨率下优先保持结构，空间不足时优先保证控件最小可用尺寸。“恢复默认布局”不会删除 `QSettings("AeroSimWorkbench", "UiLayout")` 中的用户记录。布局首选项不包含网格、工况、任务或求解结果等业务数据。

界面检查只覆盖默认浅色模式。集成测试检查主题入口锁定，以及旧主题记录启动后恢复浅色；
测试使用临时配置目录，不污染用户设置。`AEROSIM_THEME_SCREENSHOTS` 仅导出默认浅色截图，
`AEROSIM_PARAMETER_SCREENSHOTS` 仅导出浅色参数页和小窗口布局截图。

本地集成保留控制方程、边界条件和网格运动草稿面板，以及前处理下的抛弹管理空白页与独立图标。参数页切换不会丢失当前窗口中的草稿。

参考量页由 `ReferenceValuesPanel` 提供，包含力矩参考点、气动弦长/展长、参考面积、输入方式及来流参数。
参数类型支持单位雷诺数和静温、静温和静压、总温和总压、高度；切换仅显示相应字段并保留隐藏值。
自定义输入隐藏边界来源选择及其标签，页面切换保留草稿，清除本页草稿恢复示例默认值。
参考量页的边界来源尚未接入远场草稿，来源框提示不可获取；当前可使用自定义输入，未执行物理换算。

计算控制页由 `CalculationControlPanel` 提供：一阶迭代步数默认 2000、最大迭代步数 30000、
收敛残差 -10、残差监控阈值 100、不使用 GPU、计算进程数 4。GPU 可切换使用/不使用，
只保存窗口内草稿，不检测或启用实际硬件。导航保留编辑，清除本页草稿恢复默认值。

求解方法页由 `SolutionMethodPanel` 提供。空间离散为 Roe、Vanleer、AUSM、AUSMPW+、HLLC；
流场限制器为无、vanleer、vanalbada、hvanleer、hvanalbada。时间离散支持一/二/三阶向后差分、
优化二阶、修正四阶和强保稳三阶 Runge-Kutta。默认 HLLC、vanleer、一阶向后差分，
时间步长 0.001 s、子迭代 10；时间相关字段及标签仅在控制方程选择非定常时显示，定常时隐藏并收起行间空白，切换保留值。
CFL 渐变默认 (1,0)、(2000,5)，点数可调整；减少再增加点数保留隐藏行。开启强保稳默认关闭。
所有设置保存为 `solution-method` 窗口草稿，切换页面保留，清除本页草稿恢复默认；未调用实际求解器。

输出控制页由 `OutputControlPanel` 提供，包含续算文件、壁面结果和流场结果输出间隔；
流场变量、壁面变量和边界条件收敛历史均支持勾选、全选和反选。
流场和壁面使用相同的完整变量列表，包含两类原有变量，勾选状态各自独立。
流场默认选择压力、密度、速度 u/v/w，壁面默认选择马赫数；所有选项保存为窗口草稿，清除页面恢复默认。

初始化页包含全局与局部初始化。全局默认自定义，支持从已保存远场边界草稿或已编辑参考量草稿获取只读参数；
来源不可用时显示提示，不伪造来源。自定义参数支持静压/静温、单位雷诺数/静温、总压/总温、高度，
速度支持马赫数/攻角/侧滑角与马赫数/方向分量，切换保留隐藏字段。默认马赫数 6、静压 955 Pa、静温 60 K。
局部数量默认 0，支持箱体、圆球、圆柱体、圆锥体及各区域独立状态；形状和参数类型在表格选择，弹窗固定对应字段。
箱体为两顶点，圆球为球心/半径，圆柱体为半径/两顶心，圆锥体为两顶心/两半径；局部速度固定马赫数/攻角/侧滑角。
减少再增加数量保留草稿，设置窗口确定校验区域并提交，取消放弃修改。
所有设置仅为窗口内 `initialization` 草稿，不执行物理换算、网格筛选、流场初始化或持久化。
